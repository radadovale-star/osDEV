# osDEV Sequoia v1.01 Beta

**Um pequeno ambiente experimental desenvolvido em Python.**

O osDEV Sequoia é um projeto independente que explora a criação de uma experiência semelhante a um mini sistema operacional executado no terminal. Desenvolvido com Python, o projeto reúne comandos interativos, ferramentas básicas e jogos em um único ambiente.

Entre os recursos disponíveis estão uma calculadora, comandos de informação e limpeza de tela, Pedra, Papel e Tesoura e uma aventura narrativa inspirada na Revolta de Espártaco.

O projeto utiliza módulos Python separados para organizar suas funcionalidades e tem como objetivo evoluir gradualmente, servindo também como experiência prática de programação.

**Desenvolvedor:** Rada  
**Linguagem:** Python  
**Versão:** 1.05 Beta  
**Plataformas pretendidas:** Windows e Linux

**Estado do projeto:** versão experimental em desenvolvimento contínuo. Alguns recursos apresentam limitações conhecidas e precisam de correções e testes adicionais.

O osDEV não é um sistema operacional independente: é um programa que funciona dentro do sistema operacional hospedeiro. Seu comando `terminal` pode executar comandos reais do computador e deve ser utilizado com cuidado.

Este projeto representa uma etapa de aprendizado, experimentação e desenvolvimento independente.
